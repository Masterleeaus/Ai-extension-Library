# Example Conversations

## Emergency provider search

**User:** Find three emergency plumbers within 15 km of the current property who are open now.

**Titan Zero workflow:** resolve property coordinates through WorkCore → create provider-discovery search → show progress → stage results → disclose source and observation time → ask which candidates to match or approve.

## Supplier search

**User:** Find fibre-cement sheet suppliers near tomorrow's bathroom job.

**Titan Zero workflow:** resolve job location → search supplier category → rank by distance, category match, contactability, and freshness → show provider-reported hours without claiming stock availability.

## Provider promotion

**User:** Add Northside Plumbing to our approved provider list.

**Titan Zero workflow:** locate staged candidate → run WorkCore match → stop on ambiguity → request approval and accepted fields → call WorkCore provider command → report created provider ID and preserve source lineage.

## Territory analysis

**User:** Compare cleaning-provider coverage across our northern service area.

**Titan Zero workflow:** use selected searches/territory → count observed providers, distance bands, categories, and source coverage → present observations separately from any interpretation about market demand.
