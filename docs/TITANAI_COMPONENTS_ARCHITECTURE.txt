HOW COMPONENTS WORK
───────────────────────────────────────────────────────────────────────────────

SKILL LIFECYCLE (Example: TitanAI-Voice.call)

    Register (In Extension)
         ↓
    class TitanAIVoiceServiceProvider {
        protected function getSkills() {
            return ['call' => new VoiceCallSkill()];
        }
    }
         ↓
    UnifiedRegistry stores as: "titanai-voice.call"
         ↓
    CHATBOT: Uses skill for "handle voice call" conversation step
    AIAGENT: Uses skill as capability for agent to reference
    AICHATPRO: Uses skill as available enhancement


ACTION LIFECYCLE (Example: TitanAI-Voice.initiate-call)

    Register (In Extension)
         ↓
    class TitanAIVoiceServiceProvider {
        protected function getActions() {
            return ['initiate-call' => new InitiateCallAction()];
        }
    }
         ↓
    UnifiedRegistry stores as: "titanai-voice.initiate-call"
    With Parameters: ['recipient', 'caller_id', 'context']
         ↓
    CHATBOT: Execute during conversation ("Make a call to...")
    AIAGENT: Agent can invoke via decision logic
    AICHATPRO: Chat can trigger from user request


TOOL LIFECYCLE (Example: TitanAI-Research.web-search)

    Register (In Extension)
         ↓
    class TitanAIResearchServiceProvider {
        protected function getTools() {
            return ['web-search' => new WebSearchTool()];
        }
    }
         ↓
    UnifiedRegistry stores as: "titanai-research.web-search"
    With Schema (for LLM function calling):
    {
        "name": "titanai_research_web_search",
        "description": "Search the web for information",
        "parameters": {
            "type": "object",
            "properties": {
                "query": {"type": "string"},
                "limit": {"type": "integer", "default": 10}
            },
            "required": ["query"]
        }
    }
         ↓
    CHATBOT: Make tool available for conversation via tool use
    AIAGENT: Agent calls via function calling API
    AICHATPRO: Chat can invoke for deep research


PROMPT LIFECYCLE (Example: TitanAI-Research.expert)

    Register (In Extension)
         ↓
    class TitanAIResearchServiceProvider {
        protected function getPrompts() {

    }
         ↓
    UnifiedRegistry stores as: "titanai-research.expert"
    Returns: "You are a research expert. Your role is to..."
         ↓
    CHATBOT: Set system prompt for conversation about research
    AIAGENT: Set system prompt to guide agent behavior
    AICHATPRO: Set system prompt for chat expertise mode


NAMING CONVENTION
───────────────────────────────────────────────────────────────────────────────

All components follow same pattern:

    {extension-name}.{component-name}

Examples:
    titanai-voice.call              (Skill)
    titanai-voice.initiate-call     (Action)
    titanai-voice.transcriber       (Tool)
    titanai-voice.call-handler      (Prompt)
    titanai-voice.twilio            (Connector)

    titanai-research.deep-search    (Skill)
    titanai-research.web-search     (Tool)
    titanai-research.code-executor  (Tool)
    titanai-research.expert         (Prompt)
    titanai-research.openai         (Connector)

    titanai-email.send              (Action)
    titanai-email.parser            (Tool)
    titanai-email.gmail             (Connector)


UNIFIED REGISTRY QUERIES
───────────────────────────────────────────────────────────────────────────────

Get ALL Voice Components (Across All Types):
    $registry->getComponentsByExtension('titanai-voice')
    Returns: {
        "skills": [VoiceCallSkill, ...],
        "actions": [InitiateCallAction, ...],
        "tools": [TranscriberTool, ...],
        "prompts": [CallHandlerPrompt, ...],
        "connectors": [TwilioConnector, ...]
    }

Get All Tools for LLM Function Calling:
    $registry->getToolsForFunctionCalling('titanai-research.*')
    Returns: [
        {
            "type": "function",
            "function": {
                "name": "titanai_research_web_search",
                "description": "...",
                "parameters": {...}
            }
        },
        {
            "type": "function",
            "function": {
                "name": "titanai_research_code_executor",
                ...
            }
        }
    ]

Get All Research Prompts:
    $registry->getPrompts('titanai-research.*')
    Returns: [
        ResearchExpertPrompt,
        CodeReviewerPrompt,
        DataAnalystPrompt
    ]

Get Component by Full Key:
    $registry->getSkill('titanai-voice.call')
    Returns: VoiceCallSkill instance

Get All Components by System:
    $registry->getComponentsBySystem('chatbot')
    Returns summary of all chatbot-related components

REGISTRY ARCHITECTURE
───────────────────────────────────────────────────────────────────────────────

class UnifiedRegistry {
    
    // Storage (Internal)
    private $skills = [];       // ['titanai-voice.call' => VoiceCallSkill]
    private $actions = [];      // ['titanai-voice.initiate-call' => InitiateCallAction]
    private $tools = [];        // ['titanai-research.web-search' => WebSearchTool]
    private $prompts = [];      // ['titanai-research.expert' => ResearchExpertPrompt]
    private $connectors = [];   // ['titanai-voice.twilio' => TwilioConnector]
    
    // Registration APIs
    public function registerSkill(string $key, SkillInterface $skill)
    public function registerAction(string $key, ActionInterface $action)
    public function registerTool(string $key, ToolInterface $tool)
    public function registerPrompt(string $key, PromptInterface $prompt)
    public function registerConnector(string $key, ConnectorInterface $connector)
    
    // Retrieval APIs
    public function getSkill(string $key): ?SkillInterface
    public function getAction(string $key): ?ActionInterface
    public function getTool(string $key): ?ToolInterface
    public function getPrompt(string $key): ?PromptInterface
    public function getConnector(string $key): ?ConnectorInterface
    
    // Bulk APIs (with filtering)
    public function getSkills(string $filter = null): array
    public function getActions(string $filter = null): array
    public function getTools(string $filter = null): array
    public function getPrompts(string $filter = null): array
    public function getConnectors(string $filter = null): array
    
    // Smart APIs
    public function getToolsForFunctionCalling(string $filter = null): array
    public function getComponentsByExtension(string $extension): array
    public function getComponentsBySystem(string $system): array
    public function getSummary(): array
}


EXAMPLE: TitanAI-Voice Extension Implementation

class TitanAIVoiceServiceProvider extends BaseExtensionServiceProvider {
    
    public function getExtensionKey(): string {
        return 'titanai-voice';
    }
    
    protected function getSkills(): array {
        return [
            'call' => new VoiceCallSkill(),
            'answer' => new AnswerCallSkill(),
            'transcribe' => new TranscribeSkill(),
        ];
    }
    
    protected function getActions(): array {
        return [
            'initiate-call' => new InitiateCallAction(),
            'transfer-call' => new TransferCallAction(),
            'end-call' => new EndCallAction(),
        ];
    }
    
    protected function getTools(): array {
        return [
            'transcriber' => new TranscriberTool(),
            'call-transfer' => new CallTransferTool(),
            'conference' => new ConferenceTool(),
        ];
    }
    
    protected function getPrompts(): array {
        return [
            'handler' => new CallHandlerPrompt(),
            'support' => new CallSupportPrompt(),
            'sales' => new CallSalesPrompt(),
        ];
    }
    
    protected function getConnectors(): array {
        return [
            'twilio' => new TwilioConnector(),
            'vonage' => new VonageConnector(),
        ];
    }
}

Result: Automatic registration produces:
├─ Skills:     titanai-voice.call, titanai-voice.answer, titanai-voice.transcribe
├─ Actions:    titanai-voice.initiate-call, titanai-voice.transfer-call, titanai-voice.end-call
├─ Tools:      titanai-voice.transcriber, titanai-voice.call-transfer, titanai-voice.conference
├─ Prompts:    titanai-voice.handler, titanai-voice.support, titanai-voice.sales
└─ Connectors: titanai-voice.twilio, titanai-voice.vonage
