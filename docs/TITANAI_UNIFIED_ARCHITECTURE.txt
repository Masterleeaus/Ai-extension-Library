CROSS-TYPE ARCHITECTURE
───────────────────────────────────────────────────────────────────────────────

How a Cross-Type Extension (TitanAI-Voice) Works:

    Extension Loads
         ↓
    Check Configuration
         ├─ config('titanai.extensions.chatbot.auto_register') → YES
         ├─ config('titanai.extensions.aiagent.auto_register') → YES
         └─ config('titanai.extensions.aichatpro.auto_register') → YES
         ↓
    Register Components for Chatbot
         ├─ Register Skills: voice-call, voice-message
         ├─ Config: TITANAI_VOICE_ENABLED_CHATBOT=true
         └─ Events: Subscribe to ChatbotEvents
         ↓
    Register Components for AIAgent
         ├─ Register Actions: initiate-call, transfer-call, end-call
         ├─ Config: TITANAI_VOICE_ENABLED_AIAGENT=true
         └─ Events: Subscribe to AIAgentEvents
         ↓
    Register Components for AIChatPro
         ├─ Register Connectors: twilio, vonage
         ├─ Config: TITANAI_VOICE_ENABLED_AICHATPRO=true
         └─ Events: Subscribe to AIChatProEvents
         ↓
    Unified Service Layer
         └─ SharedAudioService, CallStateManager, TranscriptionService

CONFIGURATION EXAMPLE
───────────────────────────────────────────────────────────────────────────────

ENABLE TitanAI-Voice on ALL Systems:

    .env:
        TITANAI_VOICE_ENABLED=true
    
    config/titanai.php:
        'extensions' => [
            'chatbot' => [
                'auto_register_to_unified_registry' => true,
            ],
            'aiagent' => [
                'auto_register_to_unified_registry' => true,
            ],
            'aichatpro' => [
                'auto_register_to_unified_registry' => true,
            ],
        ]

    Result: TitanAI-Voice registers on all three systems


ENABLE ONLY on Chatbot & AIAgent:

    config/titanai.php:
        'extensions' => [
            'chatbot' => [
                'auto_register_to_unified_registry' => true,  ✓ Voice active
            ],
            'aiagent' => [
                'auto_register_to_unified_registry' => true,  ✓ Voice active
            ],
            'aichatpro' => [
                'auto_register_to_unified_registry' => false, ✗ Voice inactive
            ],
        ]

    Result: TitanAI-Voice only registers skills & actions (AIChatPro not activated)
