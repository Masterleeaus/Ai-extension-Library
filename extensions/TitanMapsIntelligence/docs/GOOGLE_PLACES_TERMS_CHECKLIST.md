# Google Places Terms Checklist

Complete this review before production activation. This is an engineering checklist, not legal advice.

- [ ] Google Cloud project and Places API (New) are enabled.
- [ ] Billing and company usage caps are configured.
- [ ] API key restrictions limit the applicable API and server environment.
- [ ] Required Google Maps attribution is displayed.
- [ ] Current field storage and caching rules have been reviewed.
- [ ] Place IDs are handled according to current policy and refreshed when required.
- [ ] No Google Maps page scraping or browser automation is used.
- [ ] No prohibited bulk media or review copying is enabled.
- [ ] Search/result retention has a defined purpose and expiry.
- [ ] Suppression and outreach governance are configured.
- [ ] The privacy notice identifies applicable external providers.
- [ ] Pricing assumptions are current; code does not hard-code Google prices.

Official references to review at activation:

- Google Places API (New) Text Search documentation
- Nearby Search documentation
- Place Details documentation
- Places policies and attribution requirements
- Google Maps Platform Terms of Service
