# Titan Template-Aware Shell — Pass 1

This pass introduces the shared responsive application shell for Titan Zero and its 13 operational apps.

## Added
- Global hamburger drawer
- Gear settings panel
- Context-aware Ask Titan launcher
- Online/offline/syncing status
- Template-aware four-item primary navigation
- 14 navigation definitions
- Mobile bottom dock and desktop rail-ready layout
- Accessible dialogs, Escape handling, reduced-motion support
- Generic chatbot fallback
